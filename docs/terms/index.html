Vous pouvez utiliser Soumaya librement pour lire, écouter et mémoriser le Coran.

Il vous est interdit :

  • de contourner les limitations techniques, les quotas ou les mécanismes d'authentification ;
  • d'utiliser le contenu coranique pour constituer des profils publicitaires, des identifiants biométriques ou pour entraîner des modèles d'apprentissage automatique sans autorisation écrite ;
  • d'afficher ou de transmettre, à partir de l'application, un contenu dénigrant l'islam, faisant la promotion d'une idéologie extrémiste, ou dénaturant le Coran ;
  • d'associer le contenu coranique à un contenu illicite, sexuel ou inapproprié ;
